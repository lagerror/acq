3、调用接口时公共参数以及签名规则
3.1 必传公共参数
        DeviceToken: 设备号，示例：22a6ac1f-2d86-be35-6582-ed5a6fa535d2，可以传一个固定字符串
        ApiName: 接口名称,请求的接口地址，示例：/v1/api/fly-read/content-extend-data
        BridgePlatformName:third_search（平台名称）
        random: 0.6953203423496153（随机数，0-1之间的随机数，保持唯一性）
        AppId：72（可知分配的应用Id）
        timestamp: 2021-10-10 01:48:06（请求时间 使用UTC时间）
        apiversion: 1.0（接口版本号，固定使用：1.0）
        appversion: 1.3.0（平台版本号，固定使用：1.3.0）
        nonce: 0sfafsafsa  ( 唯一值，只能使用一次，调用接口后该值不可再使用)
        token：2711228B469B78E93FD89E3DA883F2F6474F7069（接口签名验证参数，避免参数被篡改）3.2签名规则
  1、将参数按key=value进行拼接组成数组[key1=value1,key2=value2....]
2、对数组进行降序排序（不区分大小，排序时需全部转为大写或者小写，签名时使用原始值），排序后拼接为字符串
       sortStr = key1=value1key2=value23、将app密钥拼接在字符串最后，sha1签名后赋给token参数
     token=sha1(sortStr+app密钥)
3.3 签名相关伪代码
1、c#伪代码

1 static public Dictionary<string, string> sign(Dictionary<string, string> dic, string secret)
{
     var tmp = new Dictionary<string, string>();
     dic.ForEach((key, value) => {
         if (value != null)
         {
             tmp.Add(key, value);
         }
     });

     var strAry = new List<string>();

     tmp.ForEach((key, value) => {

         strAry.Add(key + "=" + value);

     });


     strAry.Sort((a,b)=>a.CompareTo(b));

     var str = string.Join("", strAry) + secret;

     tmp.Add("Token", Encrypter.Sha1(str));

     return tmp;


}

2. php 伪代码

 public function generateToken($params,$secret) {
    ksort($params, SORT_NATURAL | SORT_FLAG_CASE); // 按参数名自然排序（不区分大小写升序排序）
    $str = '';
    foreach ($params as $k => $v) {
        $str .= $k . '=' . $v;
    }
    $token = sha1($str+$secret);
    $params["token"]=$token;
    return $params;
}
